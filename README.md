# 鹈鹕骑单车 · Pelican Ride 3D

一只白鹈鹕骑着复古单车，穿越一片没有尽头的田野。所有模型、贴图和声音都由代码生成，不加载任何外部素材（只有 Three.js 从 CDN 加载）。

## 在线体验

https://violetscar-hui.github.io/pelican-ride/

## 本地运行

```bash
python3 -m http.server 5178
```

然后在浏览器中打开 http://localhost:5178 （ES 模块不能通过 `file://` 加载，所以需要起一个本地服务）。

## 操作

| 按键 | 作用 |
|---|---|
| `F` | 从车篮里抛出一条鱼，鹈鹕张嘴接住，鱼会顺着脖子咽下去 |
| `B` / `H` | 按车铃 / 鹈鹕叫一声 |
| `W` | 挥翅膀打招呼 |
| `空格` | 兔子跳（跳起时会张开翅膀，落地时有挤压回弹和羽毛飘落） |
| `P` | 拍照并保存 PNG |
| `←` `→` / `↑` `↓` | 变道 / 加速、减速 |
| `1`–`4` | 镜头：电影 / 环绕 / 跟随 / 侧面 |
| `N` / `M` / `U` | 昼夜循环 / 音乐 / 隐藏界面 |

## 实现要点

- **鹈鹕**（`js/pelican.js`）：脖子是每帧重建的管道网格，用平行传输标架计算，所以不会扭曲，吞鱼时会有一个鼓包沿着脖子往下走。喙带顶点颜色渐变，喉囊会膨胀和晃动。腿通过双骨骼 IK 踩踏板，翅膀通过 IK 握住车把。会眨眼，视线会在路面、镜头、飞鸟和飞来的鱼之间切换。
- **单车**（`js/bike.js`）：链条沿两个齿轮之间的真实切线路径运动，齿比 2.5:1。辐条交叉编织，高速时出现运动模糊盘。车把绕倾斜的转向轴转动，三角旗会随风飘动，夜里车灯会照亮路面。
- **世界**（`js/world.js`）：无限滚动的地形由正弦叠加生成，CPU 和 GPU 上用的是同一个高度函数。道路标线画在着色器里。42,000 根草叶带风吹摆动，树木、路灯、栅栏都在 GPU 上循环滚动，CPU 不做逐帧更新。另外还有大气天空、昼夜循环、星空、月亮、萤火虫、海鸥、远山雾气，以及会循环出现的路牌。
- **特效**（`js/fx.js`）：辉光、暗角、胶片颗粒、高速时的色差，以及尘土、火花粒子和飘落的羽毛。
- **声音**（`js/audio.js`）：全部用 Web Audio 合成：风声、胎噪、链条声、车铃、鹈鹕叫、吞咽声、白天鸟鸣、夜晚虫鸣，还有一段节拍跟随踏频的五声音阶小曲。
